# 📸 Image Gallery (goit-js-hw-08)

## 📌 Overview

This project is a simple image gallery built with JavaScript and DOM manipulation.
It allows users to view a collection of images and open them in a modal window for a full-size preview.

---

## 🚀 Features

* Dynamic gallery rendering using JavaScript
* Event delegation for handling user interactions
* Modal window with full-size image preview
* Clean and responsive layout using Flexbox
* Code formatted with Prettier

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox)
* JavaScript (ES6+)
* [basicLightbox](https://basiclightbox.electerious.com/) library

---

---

## ⚙️ How It Works

1. The gallery is generated dynamically from a JavaScript array.
2. Each image has:

   * preview version
   * full-size version
3. Clicking on an image:

   * prevents default link behavior
   * opens a modal window using `basicLightbox`
4. The modal displays the full-size image.
